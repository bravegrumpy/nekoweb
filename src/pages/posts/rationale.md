I have decided that I want to use astro for a number of reasons.

1. I am deeply familiar with a lot of <code>AstroJS</code> intricacies
1. `AstroJS` allows me to use a component based architecture _(similar to Server Side Includes provided by [NekoWeb](https://nekoweb.org))_ but allows me to preview my work locally.
1. I can include some interactivity with `React` or `Svelte`
1. I have the flexibility to use [ShadCN](https://ui.shadcn.com/) or [BaseCoat UI](https://basecoatui.com/) with all the possible customizations I may want, as everything is locally installed.
1. Plugins for [TailwindCSS](https://tailwindcss.com) work as expected.
1. I can create custom utilities, including styling that doesn't really work in [TailwindCSS](https://tailwindcss.com) such as [`clip-path`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path) or complex images for borders.

Obviously, this does not yet actually display what I can do, but it works for now.
